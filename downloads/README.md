# Direct installer downloads

These public ZIPs are generated from the installer sources by `python3 scripts/package-installer.py`. Choose macOS, Linux or Windows using the repository README's direct links, extract once into `hermes-starter-agent-installer/` and launch the included installer. The bundled template is `profiles/starter-agent/` (Starter Agent); choose your own installed profile name during setup. Existing installed profiles and state are not renamed. Public ZIP filenames keep their earlier names so bookmarked links continue to work. No GitHub account is required to download.

Downloading does not run code automatically. Network access and user approvals/sign-ins are still required during installation. `SHA256SUMS` records package hashes. CI checks packages for source freshness and ZIP integrity.
