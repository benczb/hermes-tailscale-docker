# Direct installer downloads

These public ZIPs are generated from the workshop installer sources by `python3 scripts/package-installer.py`. Choose macOS, Linux or Windows using the repository README's direct links, extract once and launch the included installer. No GitHub account is required to download.

Downloading does not run code automatically. Network access and user approvals/sign-ins are still required during installation. `SHA256SUMS` records package hashes. CI checks packages for source freshness and ZIP integrity.
