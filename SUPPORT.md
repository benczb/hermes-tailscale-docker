# Getting help

Start with the [README](README.md), [graphical installer guide](docs/gui-setup.md), [command setup guide](docs/command-setup.md)
and [agent installation guide](docs/agent-install.md). Platform limitations and
preview status apply even when an agent starts setup for you.

For an installation failure, use the bug report template in
[GitHub Issues](https://github.com/benczb/hermes-tailscale-docker/issues).
Include the OS edition/version, CPU architecture, entry point, revision, terminal
backend, failed step and redacted error. Do not attach full credential files,
OAuth JSON, access tokens or unreviewed logs.

This repository supports the companion's integration. Use official Hermes,
Docker or Tailscale support/documentation for problems isolated to those products.
No paid support, guaranteed response time or universal platform compatibility is
provided. Community testing and documented reproductions are welcome.

Security reports belong in [SECURITY.md](SECURITY.md). Community concerns follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
