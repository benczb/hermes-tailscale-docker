# Two-hour workshop exercises

Use synthetic information only. Configure your own provider in the setup wizard. Costs and provider retention terms apply.

- Ask: Load sid-board-review and review training/risk-register.csv. Return a risk matrix, information gaps and proposed owners. Review every claim.
- Ask: Draft, but do not activate, a four-week monitoring calendar for these fictional risks.
- Ask: Find one relevant current governance development using official MAS or SGX sources. Include publication date, citation and uncertainty. Web tools need separate provider configuration.
- Discuss local redaction: this MVP does not install Presidio or its models. Never send confidential originals to the model. The facilitator must provide a separately verified local redaction exercise.
- Close by checking that nothing was sent, scheduled or connected to personal accounts without approval.
